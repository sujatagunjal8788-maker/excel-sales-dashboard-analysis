# Sales Dashboard Analysis using Excel

## Project Overview
This project involves analyzing a large sales dataset containing 9,500+ records
and creating an interactive Excel dashboard to track sales performance,
profitability, and customer trends.

## Dataset
- Type: Dummy / Practice dataset
- Size: 9,500+ rows
- Format: Excel (.xlsx)

## Dataset Columns
- Row ID
- Order ID
- Order Date
- Ship Date
- Ship Mode
- Customer ID
- Customer Name
- Segment
- Country
- City
- State
- Postal Code
- Region
- Product ID
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit

## Tools & Techniques
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Excel Dashboards

## Analysis Performed
- Sales and profit trends over time
- Category and sub-category performance
- Region-wise and city-wise sales analysis
- Customer segment analysis
- Impact of discount on profit

## Dashboard Features
- Interactive filters using slicers
- Visual KPIs for sales, profit, and quantity
- Category and region-based performance views

## Learning Outcome
- Experience working with large datasets
- Advanced Excel dashboard creation
- Business insight generation from sales data

## Data Disclaimer
This dataset is a dummy dataset created for learning and practice purposes only.
